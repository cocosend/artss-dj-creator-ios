# Original starter PCM kit

Eight deterministic one-shot sounds generated by `scripts/generate-kit.py`.
48 kHz, mono 16-bit WAV, peak 0.85, short edge fades; decoded and converted to
stereo Float32 at the actual device rate before RemoteIO starts.

These are first-party starter sounds, not samples copied from third-party music
or a licensed commercial sound pack. Audio generation happens only when the
development script runs; the mobile app plays preloaded PCM.
